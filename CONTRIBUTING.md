# Guide de Contribution

Merci de votre intérêt pour contribuer à **AIMGPT** ! 🎉

## 📋 Comment Contribuer

### 1. Fork le Repository
Cliquez sur le bouton "Fork" en haut à droite du repository.

### 2. Cloner votre Fork
```bash
git clone https://github.com/VOTRE_USERNAME/AIMGPT.git
cd AIMGPT
```

### 3. Créer une Branche
```bash
git checkout -b feature/ma-nouvelle-fonctionnalite
```

### 4. Faire vos Changements
- Modifiez ou ajoutez du code
- Testez vos changements localement
- Assurez-vous que votre code suit les conventions Python (PEP 8)

### 5. Commiter vos Changements
```bash
git add .
git commit -m "description claire de vos changements"
```

### 6. Pousser vers votre Fork
```bash
git push origin feature/ma-nouvelle-fonctionnalite
```

### 7. Créer une Pull Request
Allez sur GitHub et cliquez sur "New Pull Request".

---

## ✅ Directives de Contribution

- **Code Quality**: Respectez PEP 8
- **Documentation**: Documentez vos fonctions avec des docstrings
- **Tests**: Ajoutez des tests pour vos nouvelles fonctionnalités
- **Commits**: Utilisez des messages clairs et descriptifs
- **Branches**: Créez des branches spécifiques pour chaque fonctionnalité

---

## 🐛 Signaler un Bug

Ouvrez une [issue](https://github.com/meh75gamer/AIMGPT/issues) avec :
- Une description claire du bug
- Les étapes pour reproduire
- Votre environnement (OS, Python version, etc.)

---

## 💡 Suggérer une Amélioration

Ouvrez une [issue](https://github.com/meh75gamer/AIMGPT/issues) avec le label `enhancement`.
